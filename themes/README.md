# قالب‌های سایت‌های دیگر روی همین کد

هر پوشهٔ اینجا یک قالب ظاهری است که با `SITE_THEME` در `.env` همان سایت انتخاب می‌شود
(اسکریپت `deploy/setup_site.sh` خودش این مقدار را می‌نویسد).

- `templates/` و `static/` قالب روی قالب اصلی (پوشه‌های `templates/` و `static/` ریشه) می‌نشینند.
- هر فایلی که در قالب نیست از قالب اصلی می‌آید؛ پس همهٔ تغییرهای منطق (قیمت، سفارش، درگاه، پنل) خودکار به همهٔ سایت‌ها می‌رسد.
- صفحه‌های ویترین (صفحهٔ اول، سربرگ، فوتر، کارت محصول، فهرست دسته، صفحهٔ محصول، ۴۰۴) در قالب بازنویسی شده‌اند؛
  صفحه‌های کاربردی (سبد، تسویه، حساب، لیست قیمت، پیگیری) همان قالب اصلی‌اند و فقط رنگ و فاصله‌شان با `css/theme.css` عوض می‌شود.
- اگر صفحهٔ ویترین تازه‌ای به قالب اصلی اضافه شد، `python manage.py check_theme` می‌گوید کدام قالب نسخهٔ خودش را ندارد.

| قالب | سایت |
|---|---|
| `farshestan` | farshestan.ir — «گالری گرم» (عاجی، شرابی، آجری) |
